## 性能变更

静态字符串及 Writer 入口复用已合并结果；字符串入口使用独立 Cbuf，软引用只读一次以保证并发回收安全。
Acid 使用共享函数快照及合并局部变量 Map；管道函数备用键、循环状态键和校验键 hash 在解析时计算。

内部流式输出和节点列表转交减少重复复制；辅助类型的所有权与线程约束见 [命名与执行流程](../naming.zh.md)。

## 辅助类型命名迁移

| 原名 | 现名 | 位置 | 职责 |
|:--|:--|:--|:--|
| `ContextMap` | `Cmap`，context map | `sack` | 复制调用方绑定，覆盖共享函数默认值；需要完整 Map 视图时才展开 |
| `CharWriter` | `Cbuf`，character buffer | `pack` | 用 StringBuilder 收集单次渲染的字符，生成 String |
| `Utf8Text` | `Utxt`，user-charset text | `pack` | 保存固定字符片段，按需缓存目标字符集的编码；U 从 UTF-8 扩展为 user charset |
| `Utf8Writer` | `Ubuf`，user-charset output buffer | `pack` | Writer 到 OutputStream 的适配器，使用目标字符集并保留跨片段编码状态 |

## 节点构造方法与字段迁移

`Exon.text9`、`Tock.tock9` 的 protected 字段类型由 char[] 改为 Utxt，直接访问它们的外部子类需要适配。节点的 String 构造器直接包装为 Utxt，Exon、Tick、Tock、RnaDone 的 protected Utxt 构造器支持共享固定文本。Exon、Tick、Tock、RnaDone 的 char[] 构造器已移除，外部子类的相应 super 调用需迁移。
