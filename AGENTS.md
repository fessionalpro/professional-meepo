# Repository instructions

Read and follow the [Meepo development conventions](doc/AGENTS.zh.md) before working in this repository.
The full conventions are maintained in Chinese. Code paths in that document are relative to the repository root.

If `AGETNS.local.md` exists in the repository root, read it before starting work.
It contains local developer conventions and has the highest priority among repository instructions,
overriding conflicting rules in this file, `doc/AGENTS.zh.md`, and other repository instruction files.
`AGETNS.*.md` is local-only and excluded from version control.
